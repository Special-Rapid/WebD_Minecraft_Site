SURVIVAL MODE GUIDE

マインクラフト
サバイバル完全ガイド

完全初心者向けに、初日からエンド攻略準備までを「今なにをすればいいか」が分かる順番でまとめた実践ガイドです。 各章は「やること」「理由」「失敗しやすい点」を1つずつ説明しているので、上から順に真似すれば進行できます。

1. 初日(1日目)を生き残る手順

  1. 最初の30秒: 木を4〜6個叩いて丸太を回収する。理由は作業台と木の道具に必要だから。素手で石を掘ろうとしないこと。
  2. クラフト開始: 丸太1個を木材4個に変換し、木材4個で作業台を作る。作業台を置いて木のツルハシを作る。
  3. 石ツールへ更新: 石を最低11個集め、石のツルハシ・石の斧・かまどを作る。木の道具のまま夜を迎えると採取が遅れて危険。
  4. 食料を確保: 羊・豚・牛を見つけたら先に食料を確保。空腹になる前に焼き肉を6個以上持つのが目安。
  5. ベッドを最優先: 羊毛3個+木材3個でベッドを作る。日没前に寝られれば夜の戦闘をほぼ回避できる。
  6. 最初の夜: 3x3程度の小屋を作り、ドアを付けて中で待機。松明を1〜3本置いて暗闇湧きを防ぐ。

クラフトが初めてなら、補助として 動画で見る / 記事で見る

2. 拠点づくりと基本装備を固める

  1. 帰還しやすい場所に拠点を固定: 平原・村の近く・水場の近くがおすすめ。迷子を減らせる。
  2. 最低限の設備を置く: ベッド、作業台、かまど2台、チェスト2個。これだけで採掘と料理と収納が回る。
  3. チェスト整理を最初から分ける: 「鉱石」「建材」「食料」「道具」で分ける。探す時間を減らせる。
  4. 鉄を優先回収: まず24個を目標に集める。鉄ツルハシ、鉄防具(胴+脚優先)、盾、バケツを作れる。
  5. 湧き潰しを実施: 拠点周囲に松明を置き、夜の不意打ちを防ぐ。戦闘が苦手でも生存率が上がる。

3. 鉄装備からダイヤ・エンチャントへ

  1. ダイヤ探しの前に準備: 松明32本以上、食料16個以上、予備ツルハシ1本を持ってから採掘に行く。
  2. ダイヤの使い道を固定: 最初のダイヤはツルハシを優先。黒曜石を掘れて進行が一気に広がる。
  3. エンチャントテーブル作成: 本1冊+ダイヤ2個+黒曜石4個で作れる。作業効率を上げる土台になる。
  4. 狙うエンチャント: ツルハシは効率強化と耐久力、防具はダメージ軽減を優先。修繕は後からでもOK。

4. ネザー進出からエンド準備まで

  1. ネザー突入前の持ち物: 金装備1部位、火打石と打ち金、丸石2スタック、食料、弓、予備の防具。
  2. 最初の目標を1つに絞る: ブレイズロッド回収を優先。寄り道しすぎるとロストしやすい。
  3. 帰り道を必ずマーキング: 松明や丸石で目印を連続配置。座標メモも取り、迷子を防ぐ。
  4. エンド準備: ブレイズパウダーとエンダーパールを集めてエンダーアイを作る。予備も含めて12個以上を目標。

5. エンド攻略前の最終チェック

  1. 必須装備: フル鉄以上の防具、弓、矢、水バケツ、食料、足場ブロック2スタック。
  2. 開幕行動: まずエンドクリスタルを破壊してドラゴン回復を止める。ここを飛ばすと長期戦になる。
  3. 被ダメージ対策: 吹き飛ばしで落下死しやすいので、高所作業中は常に水バケツをホットバーに置く。
  4. 倒せない時の戻り方: ポータルの位置にチェストを置き、予備食料とブロックを残しておくと再挑戦が早い。

6. 失敗しにくい進行テンプレート

  1. 1日目: ベッド作成、小屋、石ツール化。目的は「死なない環境」を作ること。
  2. 2日目: 食料安定化(畑or動物)と鉄集め。目的は探索前の土台を固めること。
  3. 3日目: 鉄防具と盾を完成し、洞窟探索を開始。無理に深追いしない。
  4. 拠点常備セット: 石ツール、食料、松明、丸石、予備防具をチェストに固定。全ロス後の復帰が早い。

7. 効率化テクニックと仕様理解の基本

  1. 採掘の目的を分ける: 「鉄だけ」「石炭だけ」のように分けると、持ち帰り後の整理が楽になる。
  2. チャンクを意識する: 拠点機能を近くに置くと移動時間が減り、作業効率が安定する。
  3. 夜の危険を管理する: 暗い場所を作らないだけで敵湧き事故が減る。戦闘力より環境整備が重要。
  4. 運要素は回転率で解決: 良エンチャントや交易は1回勝負より、試行回数を増やす方が成功しやすい。

作業台

必要素材: 木材4

用途: ほぼ全クラフトの起点

作るタイミング: スタート直後

棒

必要素材: 木材2(棒4本)

用途: ツール、武器、松明

作るタイミング: 作業台の直後

木のツルハシ

必要素材: 木材3 + 棒2

用途: 石採掘の解禁

作るタイミング: 初動1分以内

石のツルハシ

必要素材: 丸石3 + 棒2

用途: 鉄鉱石採掘

作るタイミング: 木のツルハシの直後

かまど

必要素材: 丸石8

用途: 食料を焼く、鉱石を精錬

作るタイミング: 石確保後すぐ

ベッド

必要素材: 羊毛3 + 木材3

用途: 夜スキップ、リスポーン固定

作るタイミング: 日没前までに必須

チェスト

必要素材: 木材8

用途: アイテム管理、ロスト対策

作るタイミング: 拠点を作った直後

盾

必要素材: 木材6 + 鉄1

用途: 序盤戦闘の生存率アップ

作るタイミング: 鉄を1個入手したら即作成
